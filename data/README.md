# 데이터 구축 설계서
### 개요

본 문서는 지하철 역 내 이동 안내 시스템을 위한 데이터 구축의 초기 설계도를 정의합니다.
프로젝트의 목표는 승객이 출발역 → 환승역 → 도착역으로 이동할 때,
에스컬레이터를 최대한 활용하면서 효율적인 이동경로를 단계별로 안내하는 것입니다.

---

### 데이터 구축 목적

역내 이동에 대한 안내를 단계별로 자동 제공하기 위해서는
역사 내부의 구조, 이동수단(에스컬레이터, 계단 등),
플랫폼 및 출구의 상대적 위치 관계를 정확히 파악해야 합니다.

따라서 다음을 목표로 데이터를 구축합니다:

1. 지하철 간 이동(노선 단위): 최단 경로 계산이 가능한 그래프 구조 확보

2. 역 내부 이동(공간 단위): 출구 ↔ 대합실 ↔ 환승통로 ↔ 승강장 ↔ 탑승구 간 연결 정보 구축

3. 편의시설 기반 경로 안내: 에스컬레이터 및 빠른하차 정보를 활용하여 최적의 이동 단계 생성
